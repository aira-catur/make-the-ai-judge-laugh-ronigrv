A Python program (`main.py`, standard library only, deterministic, no network)
that writes a single one-line joke about life as an AI agent to `entry.txt` in
the output directory (`MAKEFUN_OUTPUT_DIR` or `/output`). The line is 93
characters, well within the 200-character gate.
